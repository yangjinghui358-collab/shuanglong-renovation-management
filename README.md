# 双龙装饰经营管理平台

双龙装饰内部使用的经营管理系统，包含管理后台、业务 API 与自动化任务。

## 项目说明

系统用于工地、客户、采购、财务、库存、待办及内部审核等业务管理。未经授权，不得复制、传播、部署或接入真实业务数据。

本文件只提供代码开发所需的最少信息。生产域名、服务器地址、端口、目录、账号、手机号、数据库结构、内部接口、服务名称和发布流程不在 README 中公开。

## 本地开发

环境要求：Node.js 22、pnpm 11。

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
```

本地运行所需配置请从项目负责人处通过受控渠道获取。不得从生产服务器复制真实配置用于本地开发。

## 安全规则

下列内容禁止写入 README、代码、Issue、PR、聊天记录或公开文件：

- 密码、验证码、Cookie、Token、API Key 和私钥；
- 服务器 IP、SSH 用户、密钥路径和内部运维命令；
- 真实手机号、客户姓名、地址、聊天原文、图片和业务表格；
- 数据库连接串、备份、日志、生产环境变量和第三方平台凭据；
- 可直接定位生产系统的内部接口、目录、端口和服务拓扑。

仓库仅允许提交脱敏示例。真实凭据必须保存在批准的密钥管理系统或服务器受限配置中。

## 泄露处理

如果含敏感内容的文件曾发送给他人，仅删除或修改文件不能使旧副本失效。应立即通知项目负责人，确认暴露范围，并轮换文件中实际出现过的密码、Token、密钥和第三方凭据，同时注销相关会话、检查访问日志。
