## 阶段准入

- Phase 1A 接受前：SEC-01至 SEC-04、DATA-01至 DATA-04、PRIV-01、UI-01至 UI-03 全部通过。SEC-02/03 必须由服务器负责人在获得只读连接与外部扫描授权后安排执行窗口；窗口未安排时不得准入。
- Phase 1C 生产发布前：所有 P0 通过，P1 无阻断性缺陷，恢复演练与重启演练有复核记录。
- 无法执行的案例不得标记通过；必须保留当前状态、阻塞依赖、责任人和预计执行窗口。
