# 生产服务器只读盘点模板

本任务环境未配置 `SSH_HOST`/`SSH_USER`/PostgreSQL 连接参数，因此没有连接或盘点生产服务器。以下模板供授权后的 Phase 1C 只读盘点使用。

盘点只记录版本、状态、监听地址、容量和时间等元数据。不得复制环境变量值、配置密钥、数据库连接串、OSS 凭证、聊天原文、客户/员工信息或文件内容到 Git/工单。

| 项目 | 允许记录的结果 | 状态 |
|---|---|---|
| 盘点时间/执行人/复核人 | ISO 时间、角色或工单 ID | 待盘点 |
| OS/内核/架构 | 版本号与支持状态 | 待盘点 |
| CPU/内存/数据盘 | 容量、已用百分比、文件系统 | 待盘点 |
| NTP/时区 | 同步状态、`Asia/Shanghai` | 待盘点 |
| Nginx | 版本、运行状态、配置校验结果 | 待盘点 |
| 公网监听 | 端口号/协议/是否符合安全组 | 待盘点 |
| 内部监听 | 端口号与 loopback/私网范围，不记录凭据 | 待盘点 |
| PostgreSQL | 主版本、监听范围、最近备份/WAL 归档状态 | 待盘点 |
| 现有企微采集服务 | 服务名、运行/自启状态、最后成功时间 | 待盘点 |
| 运行时/进程管理 | Node/容器版本、systemd/编排状态 | 待盘点 |
| TLS 证书 | 签发者、到期日、续期机制，不记录私钥 | 待盘点 |
| 日志/轮转 | 目录类型、保留天数、容量和脱敏状态 | 待盘点 |
| 监控/报警 | 指标覆盖、通知渠道类型、最近测试时间 | 待盘点 |

只读命令也必须由服务器负责人授权后执行。如输出可能包含凭据或业务数据，不将原始输出保存到仓库，只人工录入上表允许的脱敏结论。
